# WiFi Static Monitor - MOD Version

Улучшенная версия приложения для мониторинга WiFi сети на Android TV с поддержкой отображения имени сети (SSID) и расширенными опциями настройки.

## Возможности

- 📡 Отображение статуса WiFi как оверлей на экране
- 🌐 Показ имени подключенной WiFi сети (SSID)
- 📍 Настраиваемая позиция индикатора (X, Y)
- 🎨 Регулировка прозрачности и размера
- 📝 Выбор позиции текста (справа или снизу)
- 🔤 Настройка размера шрифта относительно иконки
- ⏱️ Автоматическое скрытие через 15 секунд
- 🚀 Автозапуск при загрузке системы

## Различия от оригинала

- ✅ **Отображение SSID** - показывает имя подключенной сети
- ✅ **Переменный размер шрифта** - отдельный ползунок для контроля размера текста
- ✅ **Позиция текста** - выбор между горизонтальным (справа) и вертикальным (снизу) расположением
- ✅ **Новый пакет** - установка рядом с оригинальной версией

## Установка

1. Скачайте APK файл из раздела Releases
2. Разрешите установку из неизвестных источников в настройках
3. Установите приложение
4. Откройте приложение и нажмите на размер иконки (20/30/40)
5. Отрегулируйте позицию и другие параметры

## Требования

- Android 5.0 (API 21) и выше
- Разрешение "Отображение поверх других приложений"
- WiFi на устройстве

## Разработка

### Сборка локально

```bash
git clone https://github.com/yourusername/wifistatic-mod.git
cd wifistatic-mod
./gradlew assembleDebug
```

### Сборка через GitHub Actions

Автоматическая сборка происходит при каждом push'е на main/develop ветку.
APK файлы доступны в разделе Artifacts.
